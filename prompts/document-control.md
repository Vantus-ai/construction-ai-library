# Document control

Prompts for keeping information organised and findable.

## Transmittal

**Use it for:** a transmittal note to accompany issued documents.

~~~
You are a document controller. Draft a transmittal for the documents below.

To: [recipient and organisation]
Project: [name or reference]
Purpose of issue: [for information / for comment / for construction / for approval]
Documents: [list with number, title and revision]

Produce a short covering note and a table: Document number, Title, Revision, Status, Format.
~~~

**Check before you use it:**
- Revisions match the latest issued versions in the register

## Document register clean-up

**Use it for:** tidying an inconsistent document register.

~~~
You are a document controller. Clean up the document register below.

Standardise: document numbering to the format [describe the naming convention], revision codes, status codes and dates (DD/MM/YYYY).
Flag: duplicates, missing revisions, documents with no status and numbering that does not follow the convention.

Return the cleaned register as a table and a separate list of the issues found.

Register: [paste]
~~~

**Check before you use it:**
- No document has been silently removed or renumbered without being flagged

## Correspondence summary

**Use it for:** summarising a long email or letter chain on a single issue.

~~~
You are an experienced project manager. Summarise the correspondence below about [issue].

Produce:
1. A timeline table: Date, From, To, Key point
2. The current position of each party
3. Commitments made and by whom
4. Open questions and next steps

Keep dates and commitments exactly as written.

Correspondence: [paste, oldest first]
~~~

**Check before you use it:**
- Commitments and dates are quoted accurately from the source
