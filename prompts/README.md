# Prompts

Copy-ready prompts for construction and built environment workflows. They work with any capable AI model.

## The structure behind every prompt

Each prompt follows the same four-part structure. Use it to write your own.

| Part | What it does | Example |
| --- | --- | --- |
| Role | Tells the AI whose expertise to use | You are an experienced UK project manager |
| Task | States exactly what to produce | Draft an RFI to the structural engineer |
| Context | Gives the facts, with brackets for what changes each time | Drawing [ref], gridline [x], issue [description] |
| Format | Sets tone, length and layout | Formal, under 200 words, numbered questions |

## Getting better results

- **Paste the source.** Paste the clause, the spec section or the email rather than describing it.
- **Ask for questions first.** Add "Before you draft, ask me any questions you need answered" for complex documents.
- **Iterate.** Treat the first output as a draft. Follow up with "Make it more direct" or "Cut it to 120 words".
- **Save what works.** A prompt you refine three times is worth keeping.
