# Cost report narrative

Write a narrative a client board or project director can read in two minutes.

## Gather first
- Project type and scale
- Contract sum or budget
- Forecast final account or out-turn cost
- Movement since the last report and the reasons for each movement
- Risks and opportunities not yet in the forecast, with values if known
- Audience (client board, funder, internal) and any house style

If the user provides a spreadsheet or table, read the figures from it rather than asking.

## Structure
1. Headline position: one or two sentences on the forecast against budget.
2. Key movements: each material movement with its value and reason.
3. Risks and opportunities: what could move the forecast and by roughly how much.
4. Next steps: decisions needed and actions in hand.

Then offer a three-line version for the cover email.

## Rules
- Every figure must come from the user's data. Never invent or round figures in a way that changes meaning.
- Check that movements reconcile to the total movement and flag any difference.
- Do not describe anything as agreed if it is still under negotiation.
- Plain English, no unexplained jargon. Maximum 300 words unless asked.
- British English.
